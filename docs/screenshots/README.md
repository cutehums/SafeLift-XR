# Screenshot Checklist

No screenshots are included in the initial portfolio copy.

Before adding media, verify that:

- every visible person has approved publication;
- faces, names, room details and report identifiers are removed when necessary;
- the image does not redistribute a paid or license-restricted Unity asset;
- the screenshot accurately represents a feature present in the included source;
- captions distinguish Editor/demo behavior from verified Quest hardware behavior.

Recommended files:

- `xr-dashboard.png`
- `realtime-feedback.png`
- `avatar-review.png`
- `browser-report.png`
